DXF 图面质检：交图之前，先查一遍
DXF Drawing QA — catch drawing defects before delivery.

上传一个 DXF 文件，得到一份质检报告：重复图元、未闭合边界、宗地重叠、自相交、建筑物出宗地、缺失属性……能自动修的安全项直接修好给回你，原文件绝不动；修不了的只标出来、不偷偷改你的图形。

Upload a DXF, get a QA report. Safe items are auto-fixed into a new file; your original is never modified. Geometry defects are flagged, never silently reshaped.

它查什么 · What it checks（18 条规则，全部来自引擎代码）

类别规则查什么
图层LAYER-DEFPOINTS / LAYER-ZERO / LAYER-EMPTY图元落在不打印的 Defpoints 层、落在 0 层、定义了却没用过的空图层
几何GEOM-ZERO-LENGTH / GEOM-DEGENERATE零长度直线、只有一个点的多段线、半径 ≤ 0 的圆/弧
多段线PLINE-UNCLOSED未闭合且端点间距 ≤ 容差（语料配置 0.05）的多段线
重复ENT-DUPLICATE类型 + 图层 + 几何签名完全相同的重复图元
拓扑TOPO-SELF-INTERSECT / TOPO-OVERLAP / TOPO-CONTAINMENT / TOPO-DUP-VERTEX边界自相交（蝴蝶结多边形）、同层多边形重叠、建筑物不在宗地内、重复/近重复顶点
注记与样式TEXT-EMPTY / STYLE-TEXT-NONSTD / STYLE-DIM-NONSTD / STYLE-UNUSED空文字、文字/标注样式不在标准集内、定义了却没用过的样式
图块属性BLOCK-ATTR-MISSING / BLOCK-ATTR-DUP / BLOCK-ATTR-EMPTY测点图块缺必填属性（如 ELEV）、同一属性出现两次、属性值为空

能自动修的（安全项）：删重复图元 FIX-DUP、闭合小缺口 FIX-CLOSE、按配置重映射图层/样式 FIX-REMAP-*、清理空图层与无用样式 FIX-PURGE-*。只标不改的：零长度/退化几何、全部拓扑问题、属性问题——这些改动需要人判断。

现在不能做什么 · Honest limits

  • 只支持 DXF，不支持 DWG。DWG 输入需要另行验证转换工具的商用条款。
  • 重复判定目前是精确重复；近似重复（同形不同层、共线重叠）暂不判定。
  • 没有缝隙/碎片（gap/sliver）检测，没有批量打包、没有收费功能——这些都在“以后”清单里，不在这页假装已有。
  • 本页是静态演示页，尚未公开发布、不收集任何文件与信息。正式试用形态是本地的上传式网页壳（web.py：上传 → HTML 报告 → 修复后文件下载，20 MB 上限，文件不落盘留存）。

适合谁 · Who it's for

测绘成果质检、地籍 / 房产测绘出图前自查、CAD 交付前的图层与拓扑清理。尤其适合“图已经画完、就怕交出去被退回”的环节：先机器扫一遍，把低级问题在内部消化掉。

For surveying / cadastral / civil CAD teams doing pre-delivery self-checks: catch the low-level defects before the client or the reviewer does.
